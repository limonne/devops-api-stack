# Kubernetes Packaging

## Helm

The `helm/devops-web` directory contains a reusable Helm Chart with:

- Deployment
- Service
- ConfigMap
- Secret
- startup probe
- readiness probe
- liveness probe
- requests and limits
- development and production Values

## Kustomize

The `kustomize/helm-rendered` directory demonstrates the use of Kustomize on top of manifests generated by `helm template`.

## Extensibility

The `../extensibility/website-operator` directory contains the lab for:

- CustomResourceDefinition
- Custom Resources
- controller
- reconciliation loop
- ownerReferences
- garbage collection
